# Contributing

Thanks for interest in `localmapbench`.

## Development setup

```bash
pip install -e ".[dev]"
pytest
```

## Guidelines

- Open an issue before large design changes.
- Prefer small pull requests with tests.
- Do not commit large raw datasets; document download steps instead.
- Keep the public nested-CV protocol free of test-fold leakage.

## Code of conduct

Be respectful and constructive in issues and reviews. Harassment or personal attacks are not acceptable.
