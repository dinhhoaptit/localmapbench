# Venue shortlist — cost-aware (post-SoftwareX)

Prefer **hybrid ($0 subscription)** or **diamond OA ($0)**.

## Recommended order

### 1. *JOSS* — best immediate $0 software route
- Fee: $0. Needs installable package + short paper.

### 2. *Journal of Statistical Software* (JSS) — $0, higher bar
- Fee: $0. Full package + software-centered article; long queues.

### 3. *Computational Statistics* (Springer) — hybrid, **conditional**
- Fee: $0 on subscription route.
- Topical fit strong (simulation, algorithms, software/package reports).
- **Constraint:** homepage states the journal publishes **only special issues**. Submit only if a matching SI is open.

### 4. *Software Impacts* — small gold-OA fee
- ~USD 770 APC. Use only if a modest fee is acceptable.
