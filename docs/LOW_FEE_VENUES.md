# Low-fee / hybrid venue shortlist

Prefer **subscription hybrid ($0 APC)** or **diamond OA ($0)**.

## Top picks

| Rank | Journal | Model | Author fee | Notes |
|------|---------|-------|------------|-------|
| 1 | **JOSS** | Diamond OA | **$0** | Best immediate free software route |
| 2 | **JSS** | Diamond OA | **$0** | Stronger prestige; heavier packaging |
| 3 | **Computational Statistics** (Springer) | Hybrid | **$0** subscription | Topical fit good, but **only special issues** currently |
| 4 | **Software Impacts** | Gold OA | ~USD 770 | Small fee only if acceptable |

## Avoid

| Venue | Why |
|-------|-----|
| SoftwareX | ~USD 1560 APC |
| Statistics and Computing | Mandatory APC path |
| LSSP / CSDA / JSCS | Prior rejection |
| JCGS | Novelty bar too high |

## CompStat caveat

Homepage: publishes **only special issues**. Current open calls (sports; gretl) do not match this paper. Prefer JOSS/JSS unless a fitting CompStat SI appears.
